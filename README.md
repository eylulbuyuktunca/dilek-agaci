# Bizim Dilek Ağacımız

Supabase'e bağlı, yerel çalışan ortak dilek ağacı prototipi.

## Çalıştırma

Bu klasörde bir yerel web sunucusu başlatın. Örneğin:

```sh
python3 -m http.server 4173
```

Ardından `http://localhost:4173` adresini açın.

## Akış

- İlk kullanıcı hesap açıp bir ağaç oluşturur.
- Ağaç sahibi sınırsız kullanımlı özel davet linki üretir.
- Davet linkinden giriş yapan kullanıcı otomatik olarak ağaca katılır.
- Üyeler süs, dilek ve hediye ekleyebilir.

Uygulama henüz yayınlanmamıştır.
